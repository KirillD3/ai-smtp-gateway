# Описание тестового датасета

## Назначение

Датасет используется для валидации AI-классификатора угроз.
Каждое письмо размечено ожидаемой категорией и действием.

Цель: проверить, насколько точно DeepSeek относит письма
к одной из пяти категорий (TERRORISM, TECHNOGENIC, ILLEGAL,
OTHER_THREAT, BENIGN) и не путает угрозы с упоминаниями.
