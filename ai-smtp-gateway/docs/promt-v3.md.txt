# Промпт v3

Финальная версия промпта для DeepSeek. Синхронизирована с:
- `taxonomy_v1.md` — определения категорий
- `taxonomy-boundaries-v1.md` — правила разрешения коллизий
- `classifier-contract-v1.md` — формат входа/выхода

## 1. Что входит в промпт

Промпт состоит из **трёх частей:**

| Часть | Где хранится | Назначение |
|---|---|---|
| System prompt | `system_v3.txt` | Инструкция + правила |
| Few-shot | `few_shot_v3.json` | 12 примеров |
| User prompt | генерируется backend | Реальное письмо в JSON |

## 2. Что промпт НЕ делает

| НЕ делает | Кто делает |
