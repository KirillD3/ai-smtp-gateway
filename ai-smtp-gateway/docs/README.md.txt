## Быстрый старт

1. Прочитайте `taxonomy_v1.md` — поймите, что считаем угрозой.
2. Прочитайте `classifier-contract-v1.md` — поймите формат данных.
3. Посмотрите `dataset-description.md` — узнайте, что в тестовом датасете.
4. Сверьтесь с `acceptance-metrics.md` — какие цели у MVP.
