# Таксономия угроз v1

Определения 5 категорий для классификатора AI SMTP Security Gateway.

## Общие принципы

### Правило 1. Угроза vs упоминание

Класс присваивается, только если письмо содержит **угрозу как речевой акт** —
автор выражает намерение причинить вред.

Упоминание угрозы в третьем лице (новость, цитата, анализ) — **BENIGN**.

### Правило 2. Приоритет классов

При пересечении категорий выбирается наиболее тяжёлая:
TERRORISM > TECHNOGENIC > ILLEGAL > OTHER_THREAT > BENIGN

### Правило 3. Confidence

- `≥ 0.80` — уверенная классификация → REDIRECT
- `0.50–0.79` — сомнение → QUARANTINE (ручная проверка)
- `< 0.50` — BENIGN → DELIVER

### Правило 4. Формулировки-маркеры

Учитываются:
- Прямые угрозы («взорву», «убью», «отключу»)
- Требования («если не…, то…»)
- Указание времени/места
- Обфускация (`в3рвём`, `t3rr0r`)
- Транслит (`vzorvu`, `ubyu`)

## Класс 1: TERRORISM

### Определение
Письмо содержит прямую или косвенную угрозу совершения террористического акта,
либо призыв к нему, либо сообщение о готовящемся теракте.

### Критерии
1. Субъект — автор угрозы или группа.
2. Объект — место, люди, инфраструктура.
3. Намерение — массовый вред, запугивание.

### Индикаторы
взрыв, бомба, взрывчатка, СВУ, захват, заложники, теракт,
массовые жертвы, конкретное место и время, призыв, символика

### НЕ является TERRORISM
- новость о теракте
- историческая статья
- обсуждение фильма/книги
- цитирование новости
- политическая дискуссия
- сарказм
- юридический текст

### Действие
`REDIRECT → alerts-terrorism@`, confidence ≥ 0.80

---

## Класс 2: TECHNOGENIC

### Определение
Письмо содержит угрозу аварии техногенного характера: на промышленном объекте,
в инфраструктуре, на транспорте, либо сообщение о готовящемся выбросе/отключении.

### Критерии
1. Субъект — автор угрозы.
2. Объект — промышленный объект, энергосеть, водоканал, транспорт, АЭС.
3. Намерение — вызвать аварию, выброс, отключение.

### Индикаторы
выброс, утечка, отравление, отключение энергии, воды, связи,
диверсия, химзавод, АЭС, ГЭС, водозабор, энергосеть,
конкретное время и место

### НЕ является TECHNOGENIC
- новость об аварии
- отчёт о плановых работах
- инструкция по ТБ
- жалоба на плохую инфраструктуру
- сарказм

### Действие
`REDIRECT → alerts-technogenic@`, confidence ≥ 0.80

---

## Класс 3: ILLEGAL

### Определение
Письмо содержит угрозу противоправных действий: убийство, расправа,
поджог, вымогательство, похищение — кроме террористических и техногенных.

### Критерии
1. Субъект — автор угрозы.
2. Объект — конкретное лицо, группа лиц, имущество.
3. Намерение — причинить вред, запугать, получить выгоду.

### Индикаторы
убью, расправлюсь, найду, покалечу, подожгу, сожгу, похищу,
вымогательство, требование денег, угрозы госслужащему

### НЕ является ILLEGAL
- новость о преступлении
- юридический текст
- художественная литература
- сарказм («убью на шахматах»)
- бытовая ссора без угрозы
- жалоба в полицию

### Действие
`REDIRECT → alerts-illegal@`, confidence ≥ 0.80

---

## Класс 4: OTHER_THREAT

### Определение
Письмо содержит явную угрозу, которая не попадает в первые три класса:
биологическая, радиологическая, экологическая, киберугроза,
угроза репутации с элементами запугивания.

### Критерии
1. Субъект — автор угрозы.
2. Объект — люди, организации, инфраструктура, экосистема.
3. Намерение — причинить вред, запугать, принудить.
4. Не подходит ни под TERRORISM, ни под TECHNOGENIC, ни под ILLEGAL.

### Индикаторы
биологическое оружие, вирус, эпидемия, радиация, кибератака,
взлом, утечка данных, экологическая катастрофа, уничтожу репутацию

### НЕ является OTHER_THREAT
- новость, обсуждение, сарказм
- юридический текст
- пограничные случаи с confidence < 0.80 → QUARANTINE

### Действие
`REDIRECT → alerts-other@`, confidence ≥ 0.80

---

## Класс 5: BENIGN

### Определение
Письмо не содержит угрозы как речевого акта.

### Критерии
1. Нет субъекта угрозы.
2. Нет требования/принуждения.
3. Нет конкретного объекта и времени.
4. Упоминание угрозы — в третьем лице или в переносном смысле.

### Индикаторы BENIGN
- деловая лексика (встреча, отчёт, счёт)
- новостной заголовок
- «вчера», «произошло», «сообщается»
- цитата в кавычках
- «как в фильме», «шутка», «сарказм»
- юридические формулировки

### Действие
`DELIVER` без изменений

## Пограничные случаи

| Ситуация | Класс | Почему |
|---|---|---|
| Новость о теракте | BENIGN | Нет субъекта-угрозы |
| Цитата из фильма | BENIGN | Переносный смысл |
| Сарказм | BENIGN | Нет намерения |
| Пересылка Fwd: | BENIGN или QUARANTINE | Зависит от контекста |
| Юридический текст | BENIGN | Термин, не речевой акт |
| Политическая дискуссия | QUARANTINE | Пограничный случай |
| Обфускация | по смыслу | Нормализация обязательна |
