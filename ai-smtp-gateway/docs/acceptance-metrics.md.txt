# Метрики приёмки MVP

Критерии, по которым оценивается готовность AI SMTP Security Gateway.

## Функциональные метрики

| Метрика | Целевое | Критично |
|---|---|---|
| Recall по TERRORISM | ≥ 0.95 | ≥ 0.90 |
| Recall по TECHNOGENIC | ≥ 0.90 | ≥ 0.85 |
| Recall по ILLEGAL | ≥ 0.90 | ≥ 0.85 |
| Recall по OTHER_THREAT | ≥ 0.80 | ≥ 0.70 |

| FPR на BENIGN | ≤ 0.05 | ≤ 0.10 |
| Accuracy общая | ≥ 0.85 | ≥ 0.80 |

## Метрики по категориям

### Recall (полнота) — не пропустить угрозу
Recall = TP / (TP + FN)

**Цель:** ≥ 0.90 для каждой категории угрозы.

**Почему критично:** пропущенная угроза — это риск безопасности.

### Precision (точность) — не заспамить адресатов
Precision = TP / (TP + FP)

text

**Цель:** ≥ 0.90.

**Почему критично:** ложное срабатывание = лишняя работа для службы безопасности.

### FPR (False Positive Rate) на BENIGN
FPR = FP / (FP + TN)

text

**Цель:** ≤ 0.05.

**Почему критично:** обычные письма не должны страдать.
