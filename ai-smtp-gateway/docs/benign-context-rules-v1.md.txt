# Правила BENIGN-контекста v1

Маркеры для FAST-пропуска: когда локальный слой может доставить письмо
без вызова AI.

## 1. Проблема

В v0.8.x доля AI-вызовов — **48/70 (68.57%)**.
Из них примерно **18 benign** писем зря доходят до AI.

Причины:
- **Adjudication:** повторный AI-вызов для писем с триггерами
- **Char-Ngram:** срабатывает на обычной почте
- **Отсутствие BENIGN-контекста:** локальный слой не распознаёт
  безопасные конструкции (цитаты, фильмы, метафоры)

**Цель:** снизить AI-вызовы без threat bypass и без false alerts.

## 2. Что такое BENIGN-контекст

> **BENIGN-контекст** — синтаксическая область письма, внутри которой
> триггерные слова считаются безопасными.

**Ключевая идея:** триггер **внутри** BENIGN-контекста — безопасен.
Триггер **вне** BENIGN-контекста — собственная угроза автора → AI.

**Пример:**
- «„Убью тебя", — сказал герой» — триггер **внутри** цитаты → FAST
- «Сказал „убью" и повесил трубку. Найду тебя» — «найду» **вне** цитаты → AI

BENIGN-контекст применяется **только к письмам с триггерами**.
Письма без триггеров уходят в FAST на шаге 1 и не нуждаются в нём.

## 3. Триггерные слова

BENIGN-контекст работает только с этим списком.
Синхронизируется с промптом через CI.

**Насилие:**
убью, убей, убьёт, убийца, убийство, убит, найду, покалечу,
расправлюсь, уничтожу, уничтожены, подожгу, поджог, поджогов,
похищу, отравим, отравлю, применю

**Оружие / взрыв:**
бомба, взрыв, взрывчатка, СВУ, оружие, взорву, взорвём, взорвал

**Теракт:**
теракт, террорист, захват, заложники

**Инфраструктура:**
авария, выброс, утечка, отключу, отключим, диверсия

**Данные:**
залью, взломаю, опубликую

**Био / эко:**
вирус, эпидемия, катастрофа, отрава

**Английские:**
kill, bomb, attack, destroy, threat, blow up

**Стоп-выражения (не триггеры):**
«убью время», «убить время», «убийца задачи» — идиомы.
Наличие только этих фраз не активирует BENIGN-контекст.

**Файл:** `backend/app/classifier/data/triggers.json`.
Изменения вносятся синхронно с промптом.

## 4. Категории BENIGN-контекста

Семь категорий. Каждая — с маркерами и защитой.

**Маркеры бывают сильные и слабые:**
- **Сильный** — 1 достаточно
- **Слабый** — нужно 2+

**Условие срабатывания категории:** 1 сильный **или** 2 слабых маркера.
Плюс защита от bypass.

### 4.1. Цитата

**Маркеры:**
- кавычки `«»`, `""`, `''` — **сильный**
- глаголы речи: «сказал», «написал», «процитировал», «заявил»,
  «ответил», «воскликнул», «цитирует» — **сильный**
- атрибуция «— сказал X» — **сильный**

**Защита:**
- **Все** триггеры внутри кавычек.
- Кавычки парные.
- Если хотя бы один триггер вне кавычек → AI.

**Примеры:**
- «„Убью тебя", — сказал герой» → FAST
- «„Мы заложили бомбу", — цитирует издание» → FAST
- «Сказал „убью" и повесил трубку. Найду» → AI (триггер вне)

### 4.2. Фильм / книга / искусство

**Маркеры:**
- «фильм», «кино», «книга», «роман», «спектакль», «сериал»,
  «игра», «сюжет», «герой», «персонаж» — **сильный**
- название в кавычках — **сильный**
- «посмотрел», «прочитал», «рекомендую», «смотрел» — **слабый**

**Защита:**
- Триггер **в том же предложении**, что и маркер.
- Если триггер в другом предложении → AI.
- Если есть собственная угроза автора → AI.

**Примеры:**
- «В фильме "Осада" показан захват заложников» → FAST
- «Посмотрел "Осаду", захват — страшно, надо быть готовым» → AI

### 4.3. Пересылка (Fwd)

**Маркеры:**
- префикс темы `Fwd:`, `FW:`, `Переслано:` — **сильный**
- «пересылаю», «пересылаю тебе» — **сильный**
- «смотри что прислали», «прислали мне», «получил от» — **слабый**
- `---------- Forwarded message ----------` — **сильный**

**Защита:**
- **Нет вложений.** Если есть вложения → AI (вложение может содержать угрозу).
- Нет собственной угрозы автора.
- 2+ маркера.

**Примеры:**
- `Fwd: Угроза` + «Пересылаю, что прислали» → FAST
- `Fwd: Угроза` + вложение `.pdf` → AI
- `Fwd: Угроза` + «И я так сделаю» → AI

### 4.4. Метафора / сарказм

**Маркеры:**
- **Игровой контекст:** «шахматы», «футбол», «карты», «спорт», «игра» — **сильный**
- **Бытовой контекст:** «уборка», «задача», «работа», «экзамен», «дедлайн», «учёба», «ремонт» — **сильный**
- **Цифровой контекст:** «чат», «форум», «твит», «пост», «комментарий» — **сильный**
- **Маркеры сарказма:** «шутка», «сарказм», «😂», «:)», «рофл», «прикол», «в шутку» — **слабый**

**Защита:**
- Триггер **в том же предложении**, что и маркер.
- Триггер не в контексте физического вреда.
- 1 сильный или 2 слабых маркера.

**Примеры:**
- «Убью тебя на шахматах» → FAST (1 сильный)
- «Директор — террорист по дедлайнам» → FAST (1 сильный)
- «Убью тебя. Шутка.» → AI (триггер и маркер в разных предложениях)
- «Убью время» → FAST (стоп-выражение)

### 4.5. Завершённый инцидент

**Маркеры:**
- прошедшее время глагола: «произошёл», «случился», «задержан»,
  «погиб», «пострадал», «предотвратили», «раскрыт», «участились» — **сильный**
- указание на прошлое: «вчера», «на прошлой неделе», «в 2023 году» — **сильный**
- новостные обороты: «сообщается», «стало известно», «по данным»,
  «по информации» — **слабый**

**Защита:**
- **Все** глаголы-триггеры в прошедшем времени. Если хотя бы один
  в будущем — AI.
- Нет призыва к действию.
- Нет требования.
- 2+ маркера.

**Примеры:**
- «Вчера произошёл теракт, погибло 10» → FAST
- «Завтра произойдёт теракт» → AI
- «Задержан подозреваемый» → AI (только 1 маркер)

### 4.6. Юридический текст

**Маркеры:**
- «договор», «контракт», «соглашение», «приложение» — **сильный**
- «статья», «пункт», «раздел», «клауза» — **сильный**
- «основание для», «влечёт за собой», «предусмотрено» — **слабый**
- «в случае», «в соответствии с», «согласно» — **слабый**

**Защита:**
- Нет прямого личного обращения.
- Нет личной угрозы.
- 2+ маркера.

**Примеры:**
- «В договоре указано, что угроза — основание для расторжения» → FAST

### 4.7. Аналитический текст

**Маркеры:**
- «эксперты», «аналитики», «исследование», «отчёт», «обзор» — **сильный**
- «обсуждают», «рассматривают», «анализируют» — **сильный**
- «прогноз», «тенденция», «динамика» — **слабый**
- статистика, цифры, проценты — **слабый**

**Защита:**
- Нет собственной угрозы автора.
- 2+ маркера.

**Примеры:**
- «Эксперты обсуждают угрозу катастроф» → FAST
- «Эксперты обсуждают. А я устрою катастрофу» → AI

## 5. Алгоритм применения
ВХОД: нормализованное письмо

Шаг 1. Найти триггеры.
└── Триггеров нет → FAST → DELIVER.

Шаг 2. Найти BENIGN-контекст.
Категории: Цитата, Фильм, Пересылка, Метафора,
Завершённый, Юридический, Аналитический.

Шаг 3. Проверить условие категории.
└── 1 сильный или 2 слабых маркера + защита пройдена.

Шаг 4. Проверить, все ли триггеры внутри BENIGN-контекста.
└── Все внутри → FAST → DELIVER.
└── Хотя бы один вне → AI.

ВЫХОД: FAST (DELIVER) или AI

text

**Ключевой момент:** триггер вне BENIGN-контекста — это собственная
угроза автора, независимо от того, что остальные триггеры безопасны.

## 7. Защита от bypass — контрольные тесты

### 7.1. Угрозы (30 штук)

Все 30 угроз не имеют BENIGN-контекста (нет цитат, фильмов,
пересылок, метафор, прошедшего времени). → AI.

| ID | Триггер | Что помешало BENIGN |
|---|---|---|
| terrorism_01 | взорвём | Нет контекста, будущее |
| terrorism_02 | заложили | Первое лицо, требование |
| terrorism_03 | захват | Будущее |
| terrorism_04 | уничтожены | Призыв, идеология |
| terrorism_05 | сгорит | Групповой субъект, будущее |
| terrorism_06 | в3рвём | Обфускация |
| terrorism_07 | placed | Первое лицо (en) |
| terrorism_08 | жертвы | Будущее |
| technogenic_01–08 | выброс / отравим | Нет контекста, будущее |
| illegal_01–08 | найду / убью | Прямое обращение, первое лицо |
| other_01–06 | залью / взломаем | Первое лицо, требование |

**Итог:** 0 из 30 угроз уйдут по FAST.

## 9. Что не входит

- **Обфускация** — задача Char-Ngram.
- **Adjudication** — отдельный механизм (см. следующий артефакт).
- **HTML-нормализация** — задача normalizer.
- **Многоязычные метафоры** (кроме ru/en).
